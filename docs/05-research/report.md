# Research Report

Academic structure, 10–15 pages excluding lab screenshots. Grading weight: 2/3 research, 1/3 lab.

## Structure

1. **Abstract**
2. **Table of Contents**
3. **Introduction**
4. **Problem Statement**
5. **Threat** — mobile threats, APTs, backdoors, malware, spyware on Android/iOS.
6. **Risk**
7. **Mitigating Controls**
8. **Detection** — the AI SOC-analyst approach; how the agent maps signals to ATT&CK.
9. **Protection**
10. **Lab Experiment** — reference the [Lab Manual](../04-lab/lab-manual.md).
11. **Conclusion**
12. **References** — see the curated [References](references.md) page (journals, conference papers, standards).

## Framing

Agent = Tier-1 SOC analyst; me = Tier-2/3 analyst and incident responder; agent output feeds human decisions. This mirrors how AI is actually used in real SOCs.
